# Prompt templates used for this fixture

This handout is a **test fixture**, not teaching material. It is written by hand
so that the suite has something tracked in git to run against — see
`plan/app-changes.md`, 2026-08-23, gap 6. The `generation` blocks say
`model: human` because they were, and the template names below exist so the
fixture exercises the same provenance fields a real handout carries.

## `analogy_first_fixture_v1` (version A)

> Open with a concrete everyday situation, build the intuition fully, and only
> then connect it to notation.

## `formal_first_fixture_v1` (version B)

> State the definition first, then unpack each term, then give one small
> example.

## `code_first_fixture_v1` (version C)

> Open with a short runnable snippet, then explain what each line is doing.
