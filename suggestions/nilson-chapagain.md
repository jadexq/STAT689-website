# STAT 689 website suggestions

Nilson Chapagain

1. **Add a simple course website.** I like walking around the Virtual Campus. I would also add a regular website like the Stanford example we saw in class. Students could open the schedule, lecture notes, handouts, and announcements directly. Both versions should show the same course information.

2. **Make things easier to find.** A new student may see the Library without knowing they need to walk inside to see the readings. Add a small menu beside the map with links like “Find lecture notes” and “Open my handouts.”

3. **Show important updates on the home page.** Put class cancellations, deadline changes, and the next assignment at the top. Link to the latest lecture notes so students can catch up after missing class.

4. **Give students a clear next step.** Show when the TA Office is busy before students walk there. Add a Retry button if handouts fail to load. Make equations readable in TA chat and link to the course notes used in each answer.
